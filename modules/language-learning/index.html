Language acquisition

Language Learning: Evidence from Errors

Treat non-adult forms as data, then test what kind of learning process could have produced them.

1 Diagnose an error2 Trace development3 Test a hypothesis4 Build evidence
Learning objectives
  • Distinguish systematic generalization from isolated performance.
  • Interpret a U-shaped developmental pattern.
  • Compare imitation, random-error, and rule-learning accounts.
  • Design evidence for a warranted acquisition claim.
Step 1

Step 2

Reconstruct a learning path

Correct performance need not improve in a straight line. Place the observations in developmental order.

Scope: This three-part sequence is a teaching model of U-shaped development, not a fixed timetable that every learner follows.

Exit question

When does an error become evidence?

Name the comparison that would help you distinguish a developing grammatical pattern from a temporary production lapse.

Sources and scope notes
  • Berko, J. (1958). The child's learning of English morphology.
  • Marcus, G. F., et al. (1992). Overregularization in language acquisition.
  • Brown, R. (1973). A First Language: The Early Stages.

The activity uses compact, illustrative English data. Acquisition paths vary across children, structures, languages, interactional settings, and multilingual experience. Non-adult forms should not be used diagnostically outside a valid assessment.

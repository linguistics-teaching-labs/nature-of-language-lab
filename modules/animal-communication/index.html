Communication systems

Animal Communication Evidence Lab

Compare particular capabilities before applying an all-or-nothing label.

1 Inspect features2 Compare systems3 Plan evidence4 Conclude
Learning objectives
  • Describe major features of human language.
  • Analyze evidence from animal communication.
  • Compare systems feature by feature.
  • Draw conclusions proportional to the evidence.
Step 1

Inspect the evidence matrix

Select a communication system and examine what has been demonstrated.

Design featureEvidence statusWhat the evidence shows

Important: “Not demonstrated” does not mean “proved impossible.” It identifies a limit of the available evidence.

Step 2

Compare without collapsing

Place two systems side by side. Similarity on one feature need not imply equivalence on all others.

Step 3

Plan a stronger test

Select all and only the evidence needed to evaluate a communication capability.

Evidence plan
Step 4

Choose a warranted conclusion

Move from feature-level evidence to a system-level claim carefully.

Best-supported conclusion

Exit question

Which feature would you test next?

State what behavior would count as evidence and what alternative explanation you would need to exclude.

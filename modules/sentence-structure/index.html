Syntax and constituency

Sentence Structure: Find the Ambiguity

Make invisible groupings visible, then test what each grouping predicts.

1 Build a reading2 Test a constituent3 Judge form4 Conclude
Learning objectives
  • Connect alternative structures to alternative meanings.
  • Use replacement and movement as constituency evidence.
  • Separate grammaticality from semantic plausibility.
  • Explain ambiguity without labeling language illogical.

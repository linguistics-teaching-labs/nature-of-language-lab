NL Nature of Language Lab

Open teaching modules

Test familiar claims about how language works.

Guided activities for evidence-based reasoning about language. Everything runs locally in the browser—no account, installation, or programming required.

Built to be extended

Each activity is self-contained, with editable teaching text and data. Instructors can revise a case or add a module without maintaining a server.

Created and maintained by Wei Lai and Desen Lin as an instructional project.

Designed for instruction and exploratory analysis. Activities use simplified cases and teaching data and should not be treated as complete descriptions of languages or communities.
